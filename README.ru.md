# Tunetop

Маленький виджет управления музыкой поверх всех окон для Windows.

*[English version](README.md)*

![скины](docs/skins.png)

Работает через системное управление медиа Windows (SMTC), поэтому управляет **любым**
приложением, которое регистрируется в системном плеере: Spotify, браузеры (YouTube,
Яндекс Музыка, SoundCloud, VK), foobar2000, AIMP, MusicBee, VLC, Медиапроигрыватель,
Telegram и другими. Плагины для конкретных плееров не нужны.

## Возможности

- **Виджет поверх всех окон** — без рамки, перетаскивается мышью, прилипает к краям экрана
- **Кнопки** previous / play-pause / next, обложка альбома, название и исполнитель
- **Прогресс трека** с перемоткой кликом (если источник публикует таймлайн)
- **Скины** — папка с `skin.json`: цвета, размеры, шрифты, скругления, фон, свои иконки.
  В комплекте Dark, Light, Neon, Glass
- **13 языков интерфейса**, по умолчанию — как в Windows
- **Глобальные горячие клавиши** — показать/свернуть, play/pause, next, prev, громкость
- **Трей** — иконка с текущим треком в подсказке и меню со всеми командами
- **Выбор источника** — текущий плеер Windows или жёстко выбранное приложение
- **Компактный режим** — узкая полоска только с кнопками (двойной клик по виджету)
- **Автозапуск с Windows**, старт свёрнутым в трей, прозрачность, фиксация положения
- Запускается один экземпляр; повторный запуск просто показывает работающий виджет

## Установка и запуск

Нужен Python 3.10+ (проверено на 3.12).

```bat
run.bat
```

При первом запуске `run.bat` сам создаст виртуальное окружение и поставит зависимости,
дальше будет просто запускать виджет без окна консоли.

Если что-то не работает — `run-debug.bat` делает то же самое, но с видимой консолью.

Вручную:

```bat
python -m venv .venv && .venv\Scripts\pip install -r requirements.txt && .venv\Scripts\pythonw main.py
```

## Управление

### Мышь

| Действие | Что делает |
|---|---|
| Перетаскивание за пустое место | двигает виджет (прилипает к краям экрана) |
| Двойной клик | компактный режим ↔ обычный |
| Средняя кнопка | play / pause |
| Колесо мыши | громкость системы |
| Правая кнопка | меню (то же, что в трее) |
| Клик по полосе прогресса | перемотка |
| Наведение | показывает ⚙ (настройки), — (в трей), ✕ (выход) |

### Горячие клавиши по умолчанию

| Сочетание | Действие |
|---|---|
| `Ctrl+Alt+M` | показать / свернуть в трей |
| `Ctrl+Alt+P` | play / pause |
| `Ctrl+Alt+→` | следующий трек |
| `Ctrl+Alt+←` | предыдущий трек |
| `Ctrl+Alt+↑` / `Ctrl+Alt+↓` | громкость + / − |

Все меняются в настройках: кликните в поле и нажмите нужное сочетание.
`Esc` или `Backspace` — очистить. Клавиши `F1`–`F24` и мультимедийные можно назначать
без модификатора. Если сочетание уже занято другой программой, приложение сообщит об
этом уведомлением из трея, а не промолчит.

## Скины

Скин — это папка с файлом `skin.json`. Встроенные лежат в `skins/`, пользовательские —
в `%APPDATA%\Tunetop\skins` (кнопка «Открыть папку скинов» в настройках).

Указывать нужно только то, что меняется — остальное берётся из значений по умолчанию
или из скина, указанного в `extends`.

```json
{
  "name": "Мой скин",
  "author": "я",
  "extends": "dark",

  "size": [340, 92],
  "compact_size": [252, 40],
  "radius": 14,
  "padding": 10,
  "spacing": 10,
  "art_size": 64,
  "art_radius": 8,
  "button_size": 26,
  "button_gap": 6,
  "progress_height": 4,
  "progress_radius": 2,
  "shadow": 16,

  "background_image": "bg.png",
  "background_image_mode": "stretch",

  "colors": {
    "bg": "#242833",
    "bg2": "#171a22",
    "border": "#333947",
    "shadow": "#70000000",
    "title": "#f3f5f9",
    "artist": "#98a0b0",
    "time": "#787f8d",
    "icon": "#e4e8f0",
    "icon_hover": "#ffffff",
    "icon_disabled": "#4b515e",
    "icon_bg_hover": "#1affffff",
    "accent": "#6c8cff",
    "progress_bg": "#3a3f4b",
    "progress_fg": "#6c8cff",
    "art_placeholder": "#2a2e38",
    "chrome": "#7a8290",
    "chrome_hover": "#ffffff",
    "close_hover": "#ff5f57"
  },

  "fonts": {
    "title": {"family": "Segoe UI", "size": 10, "bold": true},
    "artist": {"family": "Segoe UI", "size": 9, "bold": false},
    "time": {"family": "Segoe UI", "size": 8, "bold": false}
  },

  "icons": {
    "play": "play.png", "pause": "pause.png",
    "next": "next.png", "prev": "prev.png"
  }
}
```

- **Цвета** — `#RRGGBB` или `#AARRGGBB` (первые два знака — прозрачность). Фон карточки
  рисуется градиентом от `bg` к `bg2`; полупрозрачные цвета дают эффект стекла (скин Glass).
- **`shadow`** — радиус тени вокруг карточки в пикселях, `0` отключает тень.
- **`background_image`** — картинка поверх фона, режимы `stretch` / `tile` / `center`.
- **`icons`** не обязательны: без них кнопки рисуются векторно и красятся в цвет `icon`.
- **Шрифты** дополнительно понимают `"italic": true` и `"letter_spacing": 0.4`.
- Раскладка подстраивается под любой `size`, так что виджет можно сделать крупнее или меньше.

После правки файла нажмите «Обновить список» в настройках — скин применится сразу.

## Переводы

В комплекте: English, Русский, Українська, Deutsch, Français, Español, Italiano, Polski,
Português (Brasil), Türkçe, 简体中文, 日本語, 한국어.

Локаль — это один JSON-файл: `_meta` и плоские пары `ключ: текст`. Положите свой файл в
`%APPDATA%\Tunetop\locales`, чтобы добавить или переопределить язык без пересборки —
файлы оттуда перекрывают встроенные с тем же кодом.
Если хотите прислать перевод в проект — см. [CONTRIBUTING.md](CONTRIBUTING.md).

## Настройки

Хранятся в `%APPDATA%\Tunetop\settings.json`, применяются сразу при изменении.
Файл можно править руками — неизвестные и повреждённые значения игнорируются, вместо них
берутся значения по умолчанию.

## Структура

```
main.py                 точка входа
app/config.py           настройки (dataclass + JSON)
app/i18n.py             загрузка переводов
app/media.py            мост к Windows SMTC (asyncio в отдельном потоке)
app/hotkeys.py          глобальные хоткеи через RegisterHotKey
app/skins.py            загрузка и слияние скинов
app/icons.py            векторные иконки
app/player_widget.py    сам виджет (полностью на QPainter)
app/settings_dialog.py  окно настроек
app/application.py      трей, меню, связывание всего вместе
app/system.py           автозапуск и клавиши громкости
locales/                встроенные переводы
skins/                  встроенные скины
tests/test_basics.py    проверки без живой медиасессии
```

Запуск тестов:

```bat
.venv\Scripts\python tests\test_basics.py
```

## Известные ограничения

- Только Windows 10/11 — SMTC появился в Windows 10.
- Прогресс и перемотка работают только с источниками, которые публикуют таймлайн.
  Spotify и браузеры публикуют, foobar2000 — нет (тогда полоса не рисуется, а не висит пустой).
- Громкость меняется системная (как мультимедийными клавишами), а не громкость
  конкретного приложения.
